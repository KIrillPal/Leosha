# Шаблоны конфигов

Скопируйте нужный файл в `code/configs/` и отредактируйте под своё окружение.

| Файл | Описание |
|------|----------|
| `client.template.yaml` | Шаблон конфига клиента (робот). Полная таблица аргументов — в [../README.md](../README.md). |
| `server.template.yaml` | Шаблон конфига сервера. Полная таблица аргументов — в [../README.md](../README.md). |
