# Исполнители режимов

В подпакете `client.executors` каждый режим работы реализован отдельным классом
с единым интерфейсом `ModeExecutor`:

- `PauseExecutor` — безопасная остановка;
- `TeleoperationExecutor` — прямое применение команд телеуправления;
- `AutonomyExecutor` — следование по траектории (упрощенный Pure Pursuit).

Такое разделение упрощает расширение: новый режим добавляется новым классом,
без переписывания цикла команд.
