# Конфиги сервера

Конфигурации хранятся в общей папке конфигов.

**Используйте:** `code/configs/` (относительно корня репозитория).

- `code/configs/server.yaml` — конфиг сервера
- `code/configs/templates/server.template.yaml` — шаблон с комментариями
- `code/configs/README.md` — таблица всех аргументов

Запуск с конфигом: `python -m server --config /path/to/Leosha/code/configs/server.yaml`
